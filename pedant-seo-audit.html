01 · Executive Summary

Ключевые выводы

pedant.ru — крупнейшая сеть ремонта в РФ с сильной информационной SEO-стратегией через 1 050 FAQ-статей, но коммерческие гео-страницы (500+) не работают органически.

Главный инсайт: сайт охватывает 99K+ ключей, но почти весь органический трафик — информационный (FAQ о проблемах с телефонами). Коммерческие запросы «ремонт айфона [город]», «замена экрана рядом» не захватываются органикой. В платном трафике конкурируют profi.ru и Яндекс Услуги, в органике — Pedant отсутствует по коммерческим запросам. Это главный разрыв.
Информационный трафик ✅

1 050 FAQ-статей генерируют основной органический трафик. Toppage: FAQ о «ноутбук выключается», «перезагружается телефон» — по 43-49 ключей на статью.

Коммерческие страницы ❌

500+ гео-страниц (/remont-apple/msk-*) не появляются в топ-50 ключей по базе keys.so. Отсутствует Schema LocalBusiness, нет canonical, нет коммерческого текста.

AI-трафик 🚀

12 467 AI-цитирований — один из лучших показателей среди сервисных сетей РФ. Рос с 0 (2024) до 25K+ (апрель 2026). EEAT на статьях (автор, фото, дата) — ключевая причина.

03 · Критические проблемы

Топ-5 блокеров роста

Технические ошибки, которые мешают коммерческим страницам попасть в органику. Устраняются до контентной работы.

1
Нет Schema.org LocalBusiness + AggregateRating на 500+ гео-страницах
Каждая страница /remont-apple/msk-belorusskaya и подобные — без Schema. Рейтинг 4.8 / 3 798 отзывов (Яндекс Карты) не передаётся в сниппет. Это gold-стандарт для локальных сервисов — конкуренты в топ-1 местных запросов используют LocalBusiness + AggregateRating.
Критично  Impact: Высокий · Effort: Средний (шаблон Nuxt)
2
Нет canonical на 500+ гео-страницах
Страницы /remont-apple/msk-belorusskaya, /remont-apple/spb-avtovo и сотни аналогичных не имеют canonical тега. При похожем контенте поисковик не определяет мастер-версию — ссылочный вес и поведенческие сигналы размываются между похожими страницами.
Критично  Impact: Высокий · Effort: Низкий (canonical в Nuxt layout)
3
Нет FAQPage Schema.org на 1 050 FAQ-статьях
1 050 статей на /faq/* — ни одна не имеет FAQPage или HowTo schema. Сайт уже получает 12 467 AI-цитирований. С разметкой: расширенные сниппеты в Яндексе (Q&A блок), рост AI-цитирований, возможное попадание в Google AI Overview. Это прямая точка роста без изменения контента.
Критично  Impact: Высокий · Effort: Средний (авто-генерация из структуры статей)
4
http:// возвращает 200 OK — нет принудительного редиректа на HTTPS
curl -I http://pedant.ru → HTTP/1.1 200 OK. HTTP-версия сайта доступна без редиректа, что создаёт потенциальное дублирование контента. QRATOR (DDoS-прокси) должен принудительно редиректить весь HTTP-трафик на HTTPS.
Важно  Impact: Средний · Effort: Низкий (настройка QRATOR)
5
99% изображений без alt-текста
Главная страница: 399/405 изображений без alt. Гео-страница: 110/146. FAQ-статья: 326/330. Это потеря SEO-сигналов изображений, плохая доступность, минус в E-E-A-T. При масштабе сайта (3 056 страниц) — тысячи пустых alt-атрибутов.
Важно  Impact: Средний · Effort: Средний (шаблонная генерация alt)
Также исправить
  • Title главной 115 символов → обрезается в выдаче (рекомендуется ≤70 для Яндекса)
  • OG type="article" на главной → должен быть "website"
  • Нет /llms.txt — AI-краулеры (GPTBot, ClaudeBot) не получают структурированный контекст о сайте
  • Нет Sitemap: директивы в robots.txt (sitemap обнаруживается только по Allow: /sitemap*)
  • HTML страниц 1.1–1.35 MB — тяжёлые страницы, вероятно медленный LCP на мобильных

08 · Роадмап 12 месяцев

План работ по приоритетам

Технический базис → FAQ-оптимизация → коммерческий прорыв → масштабирование.

Немедленно · 1–2 нед.
Технические блокеры
  • Добавить canonical тег на все гео-страницы (/remont-*/msk-* и /remont-*/spb-*) — один шаблон в Nuxt layout
  • Настроить принудительный HTTP→HTTPS редирект на уровне QRATOR
  • Добавить Sitemap: https://pedant.ru/sitemap.xml в robots.txt
  • Исправить OG type="website" на главной странице
  • Сократить title главной с 115 до ≤70 символов
Месяц 1–2
Schema.org — максимальный эффект
  • Добавить FAQPage Schema.org на все 1 050 FAQ-статей (авто-генерация из H2 + текст ответа) → расширенные сниппеты + рост AI-цитирований
  • Добавить LocalBusiness + AggregateRating Schema на все гео-страницы (адрес, часы, рейтинг 4.8, количество отзывов)
  • Добавить BreadcrumbList Schema на все страницы
  • Создать /llms.txt с описанием сервисов и географии — для AI-краулеров
Месяц 2–4
FAQ Quick Wins + борьба с каннибализацией
  • Аудит каннибализации: «ошибки айфона» (pos17) vs «ошибки на айфон» (pos20) — возможно одна статья каннибализирует другую
  • Для топ-9 Quick Win статей: переписать первый абзац (прямой ответ на вопрос в 1–2 предложениях)
  • Добавить dateModified в Schema для всех FAQ-статей 2021–2023 годов
  • Массово добавить alt-тексты к изображениям через шаблон (alt = заголовок статьи + модель устройства)
Месяц 4–12
Коммерческий прорыв — гео-страницы
  • Добавить уникальный SEO-текст (200–300 слов) на топ-50 гео-страниц: описание района, ближайшие метро, специализация точки, отзывы
  • Создать целевые страницы по типу услуги: /zamena-ekrana/iphone-15/, /zamena-akkumulyatora/samsung/ — под коммерческие запросы с WS 50K+
  • FAQ-блок на каждой гео-странице (3–5 вопросов специфичных для ремонта) + FAQPage Schema
  • Расширить FAQ: добавить 300+ новых статей по незакрытым запросам (Samsung, Xiaomi, Windows-проблемы)
  • Ссылочный профиль: 1 222 домена → 1 500+ (партнёрские страницы производителей, отраслевые СМИ)

  • /llms.txt + AI-боты Allow → рост в AI-ответах Яндекс Нейро
  • Страницы под услуги: /zamena-ekrana/iphone-15/ и подобные
Угрозы

  • profi.ru и Яндекс Услуги агрессивно растут в коммерческом трафике
  • Информационные конкуренты (hi-tech.mail.ru, lifehacker) — гигантские домены

Стратегический вывод

pedant.ru построил сильнейший информационный SEO в нише ремонта. Но коммерческий органический трафик практически отсутствует — компания полагается на Яндекс Карты и контекстную рекламу для привлечения клиентов на ремонт. Добавление Schema.org на FAQ и гео-страницы — это наименьшее усилие с наибольшим эффектом: код пишется один раз в шаблоне Nuxt, накрывает 1 550+ страниц сразу. Долгосрочно: создание коммерческих страниц-лендингов под услуги (замена экрана, замена аккумулятора) с правильной архитектурой — это путь к органическому трафику, который сейчас полностью упускается.
