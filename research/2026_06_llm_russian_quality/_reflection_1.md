## Ключевые противоречия, требующие Cycle 2

**Противоречие 1 — Токенизация: 2x vs 3x vs 7-8x**
Три потока дают несопоставимые числа, потому что меряют разные единицы (символы/токен, токены/слово, токены/предложение). Без контролируемого измерения невозможно оценить практический impactот Cyrillic-токенизаторов.

**Противоречие 2 — Детекция человеком: 66% vs 90%**
RuATD 2022 (peer-reviewed, shared task) даёт 66% — чуть выше случая. Habr-статья (Grade D) даёт 90% для "знакомых с AI". Разные популяции. Это КРИТИЧЕСКИ влияет на ответ: если 66% — человеческая редакция не работает как фильтр. Если 90% — опытный редактор достаточен.

**Противоречие 3 — BerryLM-XL gap**
Stream A: BerryLM-XL = #3 MERA (0.835), от Wildberries + Russ AI. Streams D, E: не упомянут вообще. Либо бенчмарк оторван от практики (Stream B прав), либо данные разновременны и BerryLM слишком новый для practitioner reviews.

## Конкурирующие гипотезы для Cycle 2

**H1 "Scale wins":** Глобальные frontier-модели (Claude, GPT-5.x) дают лучший русский, чем русскоспециализированные, потому что масштаб обучения доминирует над всеми другими факторами. Русскоязычные 26.49% данных в 10T корпусе достаточны для SOTA на MERA, несмотря на BPE-токенизатор.

**H2 "English accent is structural":** Качественное расхождение между AI-русским и человеческим русским (за пределами детектируемых артефактов) объясняется тем, что все multilingual модели генерируют русский через English-proximate representation space. Единственный способ его устранить — обучить модель с русскоцентричными representations (как Cyrillic-адаптированные модели). Тогда YandexGPT и GigaChat должны производить качественно другой русский — но MERA это не измеряет.

**H3 "Task determines winner":** Нет правильного общего ответа. Для журналистики/бизнес-текстов — Claude. Для SEO-контента — DeepSeek. Для юридических — GigaChat. Для разговорного — YandexGPT. "Человечность" разная для каждого регистра.

**H4 "Benchmarks measure nothing relevant":** MERA и аналоги полностью оторваны от стилистического качества текста. Реальный ответ на вопрос "кто пишет лучше по-русски" лежит вне существующего измерительного пространства. Нужен новый бенчмарк, которого нет.

METHODOLOGIST поставил глобальную уверенность: **0.35 / 1.00**. Field maturity: **CONTESTED**.
