01 · Executive Summary

Ключевые выводы

Сайт — зрелый по структуре и контенту, но технически запущенный. Блог собирает общероссийский трафик о прививках, а денежные локальные страницы висят на 12–33 позициях. Разрыв закрывается техническими фиксами и on-page-оптимизацией — без ссылочных бюджетов.

🔴 Блокеры роста
  • HTTP-дубль сайта — http:// не редиректит на https://, каждая страница живёт в двух копиях
  • sitemap.xml → 404 — при ~700 страницах; robots.txt из 4 строк ссылается на несуществующий файл
  • Canonical и Schema.org — нет нигде — 0 разметки на YMYL-сайте: ни MedicalClinic, ни Physician, ни FAQPage
  • Страницы по 1.0–1.7 МБ HTML — мегаменю инлайнится в каждую, ответ сервера ~1 сек
🟢 Точки быстрого роста
  • ФГДС и колоноскопия под наркозом — уже позиция 9, страница есть, нужен формат «цена + подготовка + врачи + FAQ»
  • «УЗИ Барнаул» — позиция 12 при 5 765 запросов/мес — один шаг до топ-10
  • Блог-локомотив — 9 из 10 самых видимых страниц. Нет ни одного конверсионного блока: гео-CTA монетизируют готовый трафик
  • «Календарь прививок» — gap-кластер на 1.08 млн Wordstat, профильная тема клиники, хаба нет ни у кого в Барнауле

03 · Критические проблемы

Топ-5 блокеров роста

Устраняются до контентной работы — иначе on-page-оптимизация даст 30–40% потенциала.

1

HTTP-версия не редиректит на HTTPS — полный дубль сайта

http://asko-med.ru отвечает 200 OK — каждая из ~700 страниц существует в двух копиях, сигналы ранжирования делятся между протоколами. Canonical, который мог бы склеить дубли, отсутствует.

GET http://asko-med.ru/ → 200 OK (нет 301 на https)
Критично 2 часа
2

sitemap.xml не существует — robots.txt ссылается на 404

Поисковики узнают о ~700 страницах только по внутренним ссылкам. robots.txt — 4 строки: не закрыты /bitrix/, /search/, /include/ (служебный PHP уже в индексе Google), нет Clean-param для ?PAGEN_1 и ?year.

robots.txt: «sitemap:http://asko-med.ru/sitemap.xml» → 404
Критично 1 день
3

Canonical отсутствует на всех контентных страницах

Единственное место с canonical — пагинация блога. При живом HTTP-дубле и параметрических URL (?PAGEN_1=, ?year=) дубли множатся без склейки.

canonical=null на главной, услугах, вакцинах, врачах, статьях
Критично 1–2 дня
4

Schema.org — 0 разметки на всём сайте

Для медицинского YMYL-сайта это прямой минус к E-E-A-T, сниппетам и AI-видимости. Нужны: MedicalClinic (главная, адреса, график), Physician (25+ врачей), FAQPage (вакцины, услуги), BreadcrumbList.

json-ld blocks = 0 на всех проверенных страницах
Высокий 1–2 нед.
5

HTML-страницы весят 1.0–1.7 МБ при ответе сервера ~1 сек

Полное мегаменю каталога инлайнится в каждую страницу — норма 100–300 КБ превышена в 5–10 раз. Бьёт по Core Web Vitals, краулинговому бюджету и LLM-краулерам (контент тонет в навигации). Композитный кэш Битрикса, судя по TTFB, не настроен.

/ → 1 598 651 байт; /diagnosis/ → 1 692 222 байт; TTFB 0.9–1.4 c
Высокий 1–2 нед.
⚠️ Среднее и мелочи (полный список — в research-файлах)

6 штук H1 на главной (баннеры слайдера) и 0 H1 на /company/info/ · шаблонные meta description на целых разделах (описание главной скопировано на десятки страниц) · карточки врачей без специальности в title · битые OG-теги (обрезанный og:title) · 170–350 картинок без alt на страницу · meta keywords на 790 символов · www-редирект сохраняет http · /llms.txt отсутствует.

10 · SWOT-анализ

Стратегическая оценка

Позиция asko-med.ru на момент аудита — июль 2026.

Сильные стороны
  • Блог-локомотив: 9 из 10 самых видимых страниц, общероссийский охват по вакцинации
  • Зрелая структура: ~700 страниц, 60 карточек вакцин, 25+ врачей, 135 страниц диагностики
  • Уникальные услуги: ФГДС/колоноскопия во сне, АСИТ, дуоденальное зондирование, выездная вакцинация
  • Профильность: вакцинальный центр с 1995 года, 2 филиала
  • Уже №3–4 по видимости среди клиник Барнаула — при неработающей технике
Слабые стороны
  • Технический долг: HTTP-дубль, нет sitemap/canonical/Schema
  • Страницы по 1.0–1.7 МБ, ответ сервера ~1 сек
  • Блог не конвертирует: 0 CTA-блоков в статьях
  • В топ-3 только брендовые запросы, деньги на 12–33 позициях
  • Шаблонные meta, карточки врачей без специальности в title
  • Словоформы не покрыты («терапевт барнаул» vs «барнаул терапевт»)
Возможности
  • ~30 денежных запросов на позициях 9–33 — дожимаются on-page
  • Gap 3 603 ключа: календарь прививок (1.08 млн), возрастные (455 тыс.)
  • privivka.spb.ru доказывает модель: vis 1 727 на той же семантике (×22)
  • Клещевой энцефалит: 787 тыс. Wordstat, Алтай — эндемик, сезон каждый год
  • AI-поиск: FAQPage + MedicalClinic разметка при нулевой конкуренции в регионе
Угрозы
  • Агрегаторы (ПроДокторов, НаПоправку, DocDoc) держат топы по врачам
  • МЕДСИ — федеральный бренд с ресурсами наращивает локальную видимость
  • YMYL: ужесточение требований Яндекса/Google к медицинским сайтам без E-E-A-T
  • Дефицит вакцин (ветряная оспа уже в дефиците) бьёт по конверсии вакцинального направления
Стратегический вывод

asko-med.ru — редкий случай, когда контентный актив уже построен, а техника — нет. Сайт входит в четвёрку клиник Барнаула по видимости с неработающим sitemap и дублем всего сайта по HTTP. При выполнении фаз 1–3 роадмапа реально выйти на уровень лидера локальной видимости за 6 месяцев и получить первые записи из блога уже в первые недели — только за счёт технических фиксов, on-page-оптимизации и конверсионных блоков в существующем контенте.
